========================================================================
คู่มือการใช้งานระบบอัปเดตอัตโนมัติผ่าน GitHub (iHAVECPU คัดลอกสินค้า + รูป)
========================================================================

ส่วนที่ 1: สำหรับคุณ (ผู้พัฒนา / คนปล่อยอัปเดต) — ตั้งค่าครั้งแรกครั้งเดียว
------------------------------------------------------------------------
1. สมัครและสร้าง Repository ใหม่บน https://github.com (เลือกเป็น Public เพื่อให้อัปเดตเข้าเครื่องแอดมินได้โดยไม่ต้องใส่รหัสผ่าน)
   สมมติว่าตั้งชื่อ Repository ว่า: ihavecpu-copy-product
2. เปิดไฟล์ "update-config.json" ด้วย Notepad แล้วแก้ค่า:
   - "githubOwner": ใส่ชื่อบัญชี GitHub ของคุณ (แทนที่คำว่า YOUR_GITHUB_USERNAME)
   - "githubRepo": ใส่ชื่อ Repository ของคุณ (เช่น ihavecpu-copy-product)
   - "branch": "main"
3. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น GitHub Repository ของคุณ
4. ส่งโฟลเดอร์นี้ (ที่มีค่า update-config.json ของคุณแล้ว) ให้แอดมินติดตั้งเป็น "ครั้งสุดท้าย"

เวลาคุณแก้บั๊กเสร็จในครั้งต่อๆ ไป:
- หากใช้ Git บนคอมพิวเตอร์: แค่ดับเบิลคลิกไฟล์ "ปล่อยอัปเดตขึ้น-GitHub.bat" ระบบจะปรับเลขเวอร์ชันใน manifest.json (เช่น 2.2.0 -> 2.2.1) และอัปขึ้น GitHub ให้อัตโนมัติ
- หรือหากอัปโหลดผ่านหน้าเว็บ GitHub โดยตรง: แค่แก้เลข "version" ในไฟล์ manifest.json ให้สูงขึ้น แล้วลากไฟล์ที่แก้ไปวางทับบนเว็บ GitHub ได้เลย

ส่วนที่ 2: สำหรับแอดมินฝ่ายขาย (ติดตั้งครั้งแรกครั้งเดียว)
------------------------------------------------------------------------
1. แตกไฟล์แล้วดับเบิลคลิก "ติดตั้งส่วนขยาย.bat"
   - สคริปต์จะคัดลอกส่วนขยายไปเก็บที่โฟลเดอร์ถาวร (%LOCALAPPDATA%\iHAVECPU-Copy-Product) เพื่อป้องกันแอดมินเผลอลบไฟล์ใน Downloads
   - สคริปต์จะสร้างตารางเวลาอัตโนมัติ (Windows Scheduled Task) คอยดึงไฟล์เวอร์ชันใหม่จาก GitHub ทุกๆ 15 นาทีและตอนเปิดเครื่อง
2. เมื่อหน้า Chrome เปิดขึ้นมา ให้กด "โหลดส่วนขยายที่คลายแพ็กแล้ว" (Load unpacked) แล้วกด Ctrl + V เพื่อวางที่อยู่โฟลเดอร์ที่สคริปต์คัดลอกไว้ให้
3. หลังจากนั้น เมื่อคุณปล่อยเวอร์ชันใหม่ขึ้น GitHub เครื่องของแอดมินจะดึงไฟล์ใหม่ลงเครื่องและตัวส่วนขยายใน Chrome จะรีโหลดเป็นเวอร์ชันใหม่ให้อัตโนมัติ! (หรือแอดมินกดปุ่มใน Popup / ดับเบิลคลิก "อัปเดตส่วนขยาย.bat" เพื่อดึงเดี๋ยวนั้นก็ได้)
