ส่วนที่ 1: สำหรับคุณ (ผู้พัฒนา / คนปล่อยอัปเดต)
------------------------------------------------------------------------
[ทำครั้งแรกครั้งเดียว]
1. เข้าไปที่ https://github.com/new (ล็อกอินบัญชี orangnakao-tech)
2. ช่อง Repository name พิมพ์ชื่อ: ihavecpu-copy-product
3. เลือกเป็น "Public" (สำคัญมาก เพื่อให้เครื่องคนอื่นดึงอัปเดตได้ทันทีโดยไม่ต้องใส่รหัสผ่าน)
   *ไม่ต้องติ๊ก Add a README file* แล้วกดปุ่ม "Create repository"
4. กลับมาที่โฟลเดอร์นี้ แล้วดับเบิลคลิกไฟล์ "ปล่อยอัปเดตขึ้น-GitHub.bat"
   กด Enter 2 ครั้ง ระบบจะส่งโค้ดทั้งหมดขึ้น GitHub ให้ทันที!

[เวลาคุณแก้โค้ด/อัปเดตในครั้งต่อๆ ไป]
- วิธีที่ 1 (แนะนำ): ดับเบิลคลิกไฟล์ "ปล่อยอัปเดตขึ้น-GitHub.bat"
  ระบบจะขยับเลขเวอร์ชันใน manifest.json ให้อัตโนมัติ (เช่น 2.4.0 -> 2.4.1) และอัปขึ้น GitHub ในคลิกเดียว
- วิธีที่ 2 (อัปโหลดผ่านหน้าเว็บ GitHub โดยตรง):
  แก้ไฟล์ที่ต้องการ และแก้เลข "version" ในไฟล์ manifest.json ให้สูงขึ้น แล้วกด Commit changes บนหน้าเว็บ GitHub ได้เลย

ส่วนที่ 2: สำหรับคนอื่น / แอดมินฝ่ายขาย (ติดตั้งครั้งแรกครั้งเดียว ไม่ต้องลงใหม่อีกเลย)
------------------------------------------------------------------------
1. แตกไฟล์ ZIP แล้วดับเบิลคลิก "ติดตั้งส่วนขยาย.bat"
   - สคริปต์จะคัดลอกส่วนขยายไปเก็บไว้ที่โฟลเดอร์ถาวร (%LOCALAPPDATA%\iHAVECPU-Copy-Product)
   - สคริปต์จะตั้งค่าระบบดึงอัปเดตอัตโนมัติเบื้องหลัง (ทุกๆ 5 นาที และทุกครั้งที่เปิดเครื่อง แบบไม่มีหน้าต่างเด้งกวนใจ)
2. เมื่อหน้า Chrome เปิดขึ้นมา:
   - เปิดสวิตช์ "โหมดนักพัฒนาซอฟต์แวร์" (Developer mode) มุมขวาบน
   - กดปุ่ม "โหลดส่วนขยายที่คลายแพ็กแล้ว" (Load unpacked)
   - กด Ctrl + V ในช่องชื่อโฟลเดอร์ (สคริปต์คัดลอกที่อยู่โฟลเดอร์ไว้ให้แล้ว) แล้วกด Select Folder
3. เสร็จสิ้น! ต่อไปเมื่อคุณอัปเดตโค้ดขึ้น GitHub เครื่องของทุกคนจะซิงก์ไฟล์ใหม่และรีโหลดส่วนขยายใน Chrome เป็นเวอร์ชันใหม่ให้อัตโนมัติโดยไม่ต้องติดตั้งใหม่!
